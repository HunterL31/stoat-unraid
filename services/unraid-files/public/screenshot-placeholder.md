# Screenshots

## File Browser Interface

The web interface provides a clean, modern file browsing experience:

### Main View
- 📁 Folder icons for directories
- 📄 File type icons (movies, music, documents, etc.)
- 📊 File size and modification date
- 🔍 Breadcrumb navigation
- 🎨 Dark theme optimized for Unraid

### Features
- **Browse**: Click folders to navigate
- **Share**: Generate links with one click
- **View**: Open files in new tab
- **Copy**: Multiple link format options

### Link Generator Modal
- Plain URL format
- Markdown format (for chat)
- HTML format
- One-click copy to clipboard
